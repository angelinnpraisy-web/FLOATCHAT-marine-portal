# FLOATCHAT-marine-portal
Marine data portal built with HTML, CSS, JS &amp; Three.js. Features a 4D interactive globe and depth profiler and also anomaly radar for ocean visualization. Includes Coral Bleaching Monitor to track reef risks, Fishing Zone Detector for sustainable zones, and GenAI integration for smart insights.
#Two extra features in same page
Coral Bleaching Monitor  
Tracks coral reef health by showing bleaching risk levels. Users can visualize hotspots (like Great Barrier Reef) and access detailed anomaly data, helping raise awareness of climate impacts on coral ecosystems.
Fishing Zone Detector  
Identifies potential fishing areas by analyzing oxygen levels and other ocean parameters. It highlights zones where fishing may be sustainable or risky, supporting better resource management.
#How it’s built  
Developed using HTML, CSS, JavaScript, and Three.js, the portal combines responsive web design with 3D visualization. The Three.js globe acts as the central explorer, allowing users to click on hotspots and dive into detailed dashboards.
